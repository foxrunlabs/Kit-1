# KitROM

## Description:
ROM source for the Kit-1 8-bit computer. This source includes the KitBIOS
C source generated from the KitBIOS repository. KitROM is based off a
PIC18F47K40 microcontroller, which will load the BIOS image from kitbios.c into
RAM, acting as a virtual ROM.
